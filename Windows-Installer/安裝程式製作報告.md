## 📋 摘要

本報告說明如何使用 **Inno Setup 6** + **WinSW (Windows Service Wrapper)** 建立專業的 Windows 安裝程式，將 NCUT 校園網自動登入腳本註冊為 **Windows 服務**，解決傳統排程工作容易被系統優化軟體停用的問題。

---

## 🔍 問題分析

### 原批次檔安裝的問題

| 問題 | 說明 |
|------|------|
| ❌ **非標準安裝** | 排程工作不在「應用程式」清單中 |
| ❌ **容易被禁用** | CCleaner、Dism++ 等會停用「非必要開機服務」 |
| ❌ **無修復機制** | 排程被刪了就沒了 |
| ❌ **使用者看不見** | 在 `taskschd.msc` 深處，一般使用者不會檢查 |
| ❌ **明文密碼輸入** | 批次檔無法安全輸入密碼 |

### Windows 服務的優勢

| 優勢 | 說明 |
|------|------|
| ✅ **正式服務** | 出現在 `services.msc` 服務清單 |
| ✅ **早期啟動** | 開機時比排程更早啟動 |
| ✅ **自動重啟** | 崩潰時自動重新啟動 |
| ✅ **不易禁用** | 優化軟體會顯示警告而非直接禁用 |
| ✅ **延遲啟動** | 可設定等待網路就緒後啟動 |

## 🚀 使用方式

### 前置需求

1. **Inno Setup 6**（免費）
   - 下載：https://jrsoftware.org/isdl.php
   - 或使用 VS Code 擴充功能：`Inno Setup ScriptEditor`

2. **WinSW**（免費）
   - 可自動下載（執行腳本）
   - 或手動下載：https://github.com/winsw/winsw/releases

---

### 步驟 1：下載 WinSW

**Windows:**
```batch
cd Windows-Installer
download-winsw.bat
```

**Linux/macOS:**
```bash
cd Windows-Installer
chmod +x prepare.sh
./prepare.sh
```

執行後會在 `files/` 目錄下載 `winsw.exe`。

---

### 步驟 2：編譯安裝檔

**方法 A：使用 Inno Setup GUI**

1. 安裝 Inno Setup 6
2. 開啟 `NCUT-Auto-Login-Setup.iss`
3. 點擊 **Build → Compile** (或按 `Ctrl+F9`)
4. 編譯完成，輸出檔案位於 `Output/` 目錄

**方法 B：使用命令列**

```batch
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" NCUT-Auto-Login-Setup.iss
```

---

### 步驟 3：安裝

1. 執行生成的 `NCUT-Auto-Login-Setup-3.0.exe`
2. 跟随安裝精靈指示：
   - 接受授權條款
   - **輸入帳號密碼**（密碼以星號隱藏）
   - 選擇安裝目錄（預設：`C:\Program Files\NCUT Auto Login`）
   - 選擇是否建立桌面捷徑
3. 安裝完成，服務自動啟動

---

### 步驟 4：驗證安裝

**方法 1：服務管理控制台**

1. 執行 `services.msc`
2. 找到「**NCUT 校園網自動登入服務**」
3. 狀態應為「**執行中**」

**方法 2：命令列**

```cmd
sc query NCUTAutoLogin
```

**方法 3：查看日誌**

```
C:\Program Files\NCUT Auto Login\logs\ncut_login_*.log
```

## 🔧 服務管理

### 基本命令

```cmd
# 切換到安裝目錄
cd "C:\Program Files\NCUT Auto Login"

# 啟動服務
winsw.exe start

# 停止服務
winsw.exe stop

# 重啟服務
winsw.exe restart

# 查看服務狀態
winsw.exe status
```

### 使用 Windows 服務管理

```cmd
# 開啟服務管理控制台
services.msc

# 或使用命令列
sc start NCUTAutoLogin
sc stop NCUTAutoLogin
```

### 修改帳號密碼

1. 開啟檔案：`C:\Program Files\NCUT Auto Login\config.ini`
2. 修改帳號密碼：
   ```
   s3b4320004
   F132369445
   ```
3. 重啟服務：
   ```cmd
   cd "C:\Program Files\NCUT Auto Login"
   winsw.exe restart
   ```

## 🛠️ 疑難排解

### 服務無法啟動

**檢查清單：**

1. 確認 Python 已安裝
2. 確認 `config.ini` 存在且格式正確
3. 檢查日誌檔：`logs\ncut_login_*.log`

**解決方案：**

```cmd
# 手動測試 Python 腳本
cd "C:\Program Files\NCUT Auto Login"
python ncut_login_service.py

# 查看完整錯誤訊息
```

### 安裝時提示缺少檔案

確認 `files/winsw.exe` 已下載完成。

```cmd
dir files\winsw.exe
```

### 服務啟動後立即停止

可能原因：

1. 帳號密碼錯誤
2. 網路未就緒
3. Python 環境問題

**解決方案：** 查看日誌檔確認錯誤原因。

### 數位簽章警告

如需移除「未知的發布者」警告，需要購買程式碼簽章證書。

在 `.iss` 檔案中添加：

```iss
SignTool=signtool.exe sign $f
SignedUninstaller=yes
```

## 📋 配置選項詳解

### WinSW 服務配置 (`winsw-service.xml`)

```xml
<?xml version="1.0" encoding="UTF-8"?>
<service>
    <!-- 服務識別 -->
    <id>NCUTAutoLogin</id>
    <name>NCUT 校園網自動登入服務</name>
    <description>自動檢測網路狀態並登入 NCUT 校園網路認證系統</description>
    
    <!-- 執行配置 -->
    <executable>%BASEDIR%\Python\pythonw.exe</executable>
    <arguments>%BASEDIR%\Scripts\ncut_login.py</arguments>
    <workingdirectory>%BASEDIR%</workingdirectory>
    
    <!-- 啟動模式 -->
    <startmode>Automatic</startmode>
    <priority>Normal</priority>
    
    <!-- 重啟配置 -->
    <onfailure action="restart" delay="5 sec"/>
    <onfailure action="restart" delay="5 sec"/>
    <onfailure action="none"/>
    
    <!-- 日誌配置 -->
    <logmode>roll</logmode>
    <logpath>%BASEDIR%\logs</logpath>
    <logtitle>NCUT Auto Login</logtitle>
    
    <!-- 超時配置 -->
    <waithint>30000</waithint>
    <sleeptime>5000</sleeptime>
    <stoptimeout>30000</stoptimeout>
</service>
```

### 關鍵參數說明

| 參數 | 說明 | 預設值 |
|------|------|--------|
| `startmode` | 啟動模式 | `Automatic`（自動） |
| `onfailure` | 失敗處理 | `restart`（重啟） |
| `delay` | 重啟延遲 | `5 sec` |
| `logmode` | 日誌模式 | `roll`（輪替） |

## 🔐 安全性說明

1. **密碼儲存：** 以明文儲存在 `config.ini`，僅本機可存取
2. **服務權限：** 以 SYSTEM 權限運行，可存取所有網路資源
3. **無網路傳輸：** 帳號密碼僅用於本機登入，不會傳輸到第三方
